Security Toolkit

Bash utilities for reconnaissance and testing: subdomains, takeover checks, link discovery, PII scanning, and blind XSS helpers.

Explore Tools How to Use

Quick Start

  1. Give execute permission: chmod +x *.sh
  2. Run a script, e.g.: ./subdomainfind.sh example.com
  3. Review results and iterate.

Tip: use --help if a script supports it.

Usage Examples

Subdomain Finder

# Make executable
chmod +x subdomainfind.sh

# Basic usage
./subdomainfind.sh example.com

# Save results
./subdomainfind.sh example.com > subdomains.txt

Takeover Checker

# Make executable
chmod +x takeover.sh

# From a list of subdomains
cat subdomains.txt | ./takeover.sh

Link Finder

# Make executable
chmod +x linkFinder.sh linkfinder.sh

# Crawl a URL or JS file
./linkFinder.sh https://example.com
./linkfinder.sh app.js

PII Scanner

# Make executable
chmod +x pii.sh

# Scan a file or stream
./pii.sh results.txt
cat responses.txt | ./pii.sh

Blind XSS Helpers

# Make executable
chmod +x bxss.sh

# Print or inject common payloads
./bxss.sh --list
./bxss.sh --inject target.txt
